the narrower Node 24 line with its observed 24.12.0 floor;
[Node documents stable type stripping at that version](https://nodejs.org/docs/latest-v24.x/api/typescript.html).
Other Node versions/platforms have not been tested in this task. Later Node
24 patches are admitted by policy, not individually verified. No interval of
untested Pi SDK or TypeBox versions is admitted. SDK-internal TypeBox 1.3.7
copies are retained by the unchanged dependency graph; the direct peer remains
the existing 1.3.14, exercised through custom review schemas/tools.

Only the root lockfile requirements changed; no installed dependency version,
global Pi installation, personal configuration or consumer repository changed.
