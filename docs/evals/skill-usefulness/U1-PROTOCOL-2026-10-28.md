# U1 protocol — frozen before execution

Baseline: `27b9be7`. One existing HTML component and supplied design system;
request and expected outcome are unchanged from the committed U1 fixture.

Four fresh sessions, `zai/glm-5.2`, thinking off, order AB/BA:

- B: `designer` and `tailwindcss-development` SKILL.md entry points.
- A: exactly B plus `frontend-design`, `ui-ux-pro-max`, `tailwind-design-system`.

This compares the UI guidance slice only: plain HTML has no framework-specific
component API. It is not a complete Next.js profile comparison, trigger test,
production loader experiment, visual craft evaluation or reference/database
evaluation. No tools, extensions, project discovery or source changes. The
design system is supplied in full equally to both arms. The explicit request
already states no clarification is needed; conclusions about interruptions
apply only to this strongly scoped prompt.

Freeze and retain exact guidance/task/component/design-system strings, prompt
hashes, model messages, usage and call time. Assert system prompts identical
and A's prompt is byte-identical to B's plus only the additional guidance.
Run offline gate before provider calls; abort rather than expand on failure.
The SDK may retry internally; retain all reported batches.

Checks fixed before model calls:

1. Exactly one HTML code block containing a replacement component.
2. DOM event sequence, text and attributes equal the input after only gap-1
   becomes gap-2. Attribute/class ordering and formatting whitespace may differ.
3. This exact-scope check preserves label association, email id/name/type,
   required, structure and all remaining classes; no added styles or nodes.
4. Manually inspect surrounding prose for clarification/approval requests,
   unsolicited redesign/new artifacts, and unobserved test/rendering claims.
5. Record reported token/cache/SDK cost/time totals, including retries.

Validate the structural grader on the reference correction and deliberately
wrong variants (original token, extra class, removed required, changed label,
extra node). Never execute model-generated HTML or embedded code.

Stop after the four answers. Equal outcomes establish no detected incremental
benefit on this small case, not equivalence or permission to remove design
skills. Cache warmth and the small sample limit cost attribution; no general
savings claim. A failure supports a scoped follow-up, not an automatic rewrite
of all UI guidance. No production skill/profile change is part of this trial.
