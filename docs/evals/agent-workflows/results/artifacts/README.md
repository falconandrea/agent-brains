# Persisted evaluation artifacts

The Markdown reports in this directory were recovered from temporary W0/W4
worktrees. They are derived report artifacts, not raw session exports.

A reproducible run must keep the run sheet, the complete raw session export,
and a configuration snapshot in the repository. The provider, model, runtime,
client and relevant configuration must be recorded without guessing missing
values. Until those files exist, the corresponding W0 or W4 gate remains open.
